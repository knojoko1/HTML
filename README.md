# HTML Learning & Practice Repository

Welcome to my HTML learning and practice repository (`knojoko1/HTML`)! This space is dedicated to mastering the building blocks of web development, learning semantic markup, structuring modern web pages, and building a solid foundation in web technologies.

---

## 📂 Repository Structure

The repository is organized into logical directories to keep code structured and easy to navigate:

*   **`basics/`**: Fundamental HTML tags, document structure, headings, paragraphs, and lists.
*   **`forms/`**: Practice with forms, input types, labels, validation, and user interaction elements.
*   **`tables/`**: Creating and styling tabular data using semantic table tags.
*   **`projects/`**: Small static web pages and landing pages built to reinforce core concepts.

---
